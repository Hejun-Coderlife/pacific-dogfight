# 太平洋空战 · Pacific Dogfight

浏览器里的 3D 空战游戏（Three.js，单个 `index.html`，无需安装）。在太平洋群岛上空驾驶现代战机，与 AI 敌机缠斗。

**在线游玩：** https://hejun-coderlife.github.io/pacific-dogfight/

## 玩法
- 11 款战机可选：F-22、Su-57、F-35、F-15E、F-16、F/A-18F、F-14、MiG-29、MiG-35、阵风、F-117
- 任务：自由空战 / 限时歼灭 / 护航 B-2 / 保卫航母；三档难度；五种天气（黄昏、正午、阴天、暴风雨、夜晚）
- 可从福特号航母弹射起飞、拦阻着舰；座舱视角；雷达；导弹与热诱弹

| 操作 | 按键 |
|---|---|
| 指向 / 机动 | 鼠标（飞机自动追准星） |
| 机炮 / 导弹 / 热诱弹 | 左键或空格 / 右键或 F / X |
| 油门（推满进加力） | W / S |
| 横滚 / 方向舵 / 俯仰 | A D / Q E / ↑ ↓ |
| 起落架 / 弹射 / 雷达量程 | G / T / M |
| 自由看 / 切镜头（含座舱） / 重新起飞 / 暂停 | 按住 C / V / R / Esc |
